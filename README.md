# 姿勢分析アプリ

- アプリ: https://ten18ys00-coder.github.io/shisei-app/
- お試し版: https://ten18ys00-coder.github.io/shisei-app/demo.html

院コードとパスコードでログインして使います。患者さんのお名前・メモ・コメントは端末で暗号化して保存され、名前を含まない測定値だけが統計に使われます。写真そのものは保存しません。

歩行分析（ほさか整骨院のみ表示）：患者さんの画面の「歩行を分析する」から、前から・後ろからの歩く動画を撮ると、片脚で支える時間の左右差・骨盤の落ち込み・上半身の傾き・膝の向きを計算します。動画は端末の中だけで解析し、保存するのは骨格の動き（目印の位置）と数値だけです。

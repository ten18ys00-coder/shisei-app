# 姿勢分析アプリ

- アプリ: https://ten18ys00-coder.github.io/shisei-app/
- お試し版: https://ten18ys00-coder.github.io/shisei-app/demo.html

院コードとパスコードでログインして使います。患者さんのお名前・メモ・コメントと撮った写真は、端末で院の鍵を使って暗号化してから保存されます（ほかの院や管理者からは読めません）。名前を含まない測定値だけが統計に使われます。

歩行分析（全院・お試し版）：患者さんの画面の「歩行を分析する」から、前から・後ろからの歩く動画を撮ると、片脚で支える時間の左右差・骨盤の落ち込み・上半身の傾き・膝の向きを計算します。動画は端末の中だけで解析し、保存するのは骨格の動き（目印の位置）と数値だけです。

姿勢の撮影は、アプリ内のカメラでガイド線（体の中心線・頭とかかとの位置・方眼）と水平線（スマホの傾きセンサーと連動）を見ながら撮れます。歩行分析は前後に1本ずつ、または2〜3mの往復でも撮れ、レポート画像（PDF・印刷・共有）も作れます。

## 更新するときの決まり（患者さんの記録を必ず引き継ぐ）

- 患者さん・姿勢の記録・歩行の記録・写真は、どの版でも同じ保存先（Supabase の patients / sessions / gait_sessions と Storage の photos）を読み書きする。保存先や形式を変えるときは、前の版で保存したものを新しい版で自動で読み込める（移せる）ようにしてから公開する。
- 表や列は「足す」だけにして、消したり名前を変えたりしない。前の版で保存したデータに無い項目があっても、画面が止まらないようにする。
- 公開する前に、前の版で記録を作り、新しい版で開いて「患者さん・記録・コメント・写真」が全部出ることを確かめる。
- 端末の中だけに残っている古い記録（hosaka-posture-v1）は、ほさか整骨院でログインしたときに自動でクラウドに移す。
- 患者さん・記録が上書き・削除されると、直前の内容がデータベースの private.record_history に90日間残る（更新の不具合で消えても戻せる）。

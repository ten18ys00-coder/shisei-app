# Re:MOVE（ほさか整骨院 運動処方）

もう一度、思いどおり動ける身体へ。 ― Structural Body Care

先生が運動メニューを選んで患者さんに渡し、患者さんはスマホで人型アニメーションを見ながら自主トレを行い、
「できた」と痛み（0〜10）・ひとことの記録が院に届くアプリです。

- 公開ページ：https://ten18ys00-coder.github.io/shisei-app/re-move/ （姿勢アプリのリポジトリ `shisei-app` の `re-move/` に置く。ソースは同じリポジトリの `remove-app/`）
- お試し版：公開ページのURLの末尾に `?demo` をつけると、架空の患者さんで試せます（データは端末内だけ）
- 先生側のログイン：院のパスコード（姿勢アプリ・栄養アプリと共通）
- 患者さん側：先生が渡すリンク（QRコード）を開くだけ。ログイン不要

## データ
Supabase（姿勢アプリと同じプロジェクト「hosaka-shisei」・東京リージョン）の専用テーブル。

| テーブル | 中身 |
| --- | --- |
| `ex_patients` | 呼び名・院内メモ・運動メニュー・患者さん用リンクの鍵 |
| `ex_logs` | 1日1行の記録（できた運動・痛み・ひとこと） |
| `ex_library` | 先生の動画URL・院オリジナルの運動 |
| `ex_plan_history` | メニューを変える前の内容 |

先生側は行単位のアクセス制御（RLS）で自院の分だけ。患者さん側は `ex_patient_view` / `ex_patient_log`
の2つの関数だけを使い、リンクの鍵に合う1人分のメニューと記録しか扱えません（記録は今日の前後7日以内）。
このリポジトリに患者データは入っていません。

## 姿勢アプリとのつながり
姿勢分析・歩行分析の結果画面「おすすめの運動」の下にある「Re:MOVEで運動を渡す」から、チェックした運動を
Re:MOVE の患者さんに「提案」（`ex_patients.proposal`）として送ります。初めての患者さんは呼び名をつけて登録し、
姿勢アプリの患者ID（`posture_patient_id`）でつなぎます（名前そのものは送りません）。
Re:MOVE ではメニュー作成画面に提案が出て、先生が選んでメニューに入れます。記録タブには姿勢スコアの変化が出ます。
ほさか整骨院（院コード hosaka）のときだけボタンが出ます。

## 運動ライブラリ
`src/data/exercises.ts`：55種類。説明文と動き（人型アニメーション）はすべて院のために新しく作ったものです。
動きは `src/figure/` の骨格モデル（関節の角度）で描いています。
`npx tsx tools/sheet.ts /tmp/sheet.svg` で全運動のポーズを一覧画像にして確認できます。
